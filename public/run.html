01

Prepare the project

Use Node.js 24+, npm, your API key and model access. Windows needs Git Bash if the SDK cannot locate it. npm test runs only in a fresh private classroom copy.

cd .\agent-sdk\lesson21-built-in-tools
02

Install and configure

Preserve an existing .env, otherwise copy the safe example. Enter your key locally; the startup script explicitly loads this file.

npm ci
if (!(Test-Path .env)) {
  Copy-Item .env.example .env
}
notepad .env
03

Start the application

Open port 3121 and keep the terminal running. The five linked pages cover the lab, learning goals, setup, architecture and implementation.

npm start
# http://127.0.0.1:3121
04

Search, read and repair

Run Read-only, then Repair. Inspect the actual call trace and before/after files. Host test exit 1 before repair and 0 afterward verify the change; tests and scripts must remain unchanged.

npm run sample:env -- read-search
npm run sample:env -- repair
05

Compare rule layers

Run Allow rule, Bare deny and Scoped deny. Compare availability, attempts, completed calls and callback requests. The harmless extra script must not execute.

npm run sample:env -- allow-rule
npm run sample:env -- bare-deny
npm run sample:env -- scoped-deny
06

Protect dummy data and inspect MCP-only mode

Run Protect file and inspect whether a Read was attempted; an advance refusal is recorded separately. Then run MCP only to call one constant tool with no built-ins in context.

npm run sample:env -- protect-file
npm run sample:env -- mcp-only
npm test

Your .env configuration

ANTHROPIC_API_KEY=your_api_key
CLAUDE_MODEL=claude-sonnet-4-6
PORT=3121
# Windows if needed: CLAUDE_CODE_GIT_BASH_PATH=C:/Program Files/Git/bin/bash.exe

The real key remains on the server. Restart after edits; existing shell values take precedence. No Managed Agents resource ID is needed.

Troubleshooting

Use the URL printed by startup. If another process occupies the port, change PORT. On Windows configure CLAUDE_CODE_GIT_BASH_PATH if needed. Keep optional npm dependencies enabled. Inspect actual tools in initialization and distinguish native permission rules from the host guard. A failed query is never replaced by a saved answer.
